# ChatGPT: пакетная генерация изображений CONTROL

GPT-адаптация реального расширения `Gemini Prompt Queue Control 2.3.1` из предоставленного владельцем архива. Сохранены: очередь, префикс/суффикс, интервалы, пауза/остановка, повторы, live-лог, прогресс, сквозная нумерация `slide_001…` и сбор скачиваемого ZIP.

## Настройки по умолчанию для ChatGPT

- Новый чат после каждых N картинок: `0` — вся очередь остаётся в одном чате, удобнее для одного ZIP.
- Интервал после завершения: `0.2` минуты.
- Максимум ожидания картинки: `120` секунд.
- Пауза после результата: `10` секунд.
- Повторы: `2`.

На предоставленной записи создание одной картинки в ChatGPT заняло примерно 47 секунд (от отправки до готового кадра); 120 секунд оставлены как безопасный предел, а не как обязательная пауза.

## Установка

1. Распакуй ZIP в отдельную папку.
2. Открой `chrome://extensions` и включи **Режим разработчика**.
3. Нажми **Загрузить распакованное расширение** и выбери папку с `manifest.json`.
4. Открой `https://chatgpt.com/` и нажми значок расширения: появится правая панель.
5. Вставь промты (один на строку), настрой префикс/суффикс и нажми **Запустить очередь**.
6. После завершения нажми **Скачать картинки этой страницы ZIP**.

## Границы

- Расширение работает только на `chatgpt.com` / `chat.openai.com`.
- Не хранит пароль, cookies, токены или API keys.
- Не обходит CAPTCHA, лимиты, подтверждения или правила ChatGPT.
- Не обновляй страницу до скачивания ZIP: накопитель изображений живёт в текущей вкладке.
- Первый запуск: только `Малый тест` с 2–3 промтами. Если ChatGPT изменил разметку, пришли скрин результата и лога — адаптируем точечно.
